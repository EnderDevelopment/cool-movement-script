# Roblox Sprint Movement Script

This script allows players to sprint when they press the Shift key. The sprint speed can be adjusted by changing the `sprintSpeed` variable in the script. It is a simple and effective way to enhance player movement in Roblox games.

## Installation

1. Open Roblox Studio.
2. Create a new script or open an existing one.
3. Copy and paste the contents of `sprint_movement_script.server.lua` into the script.
4. Save the script and test it in the game.

## Usage

- Press the Shift key to start sprinting.
- Release the Shift key to stop sprinting.
